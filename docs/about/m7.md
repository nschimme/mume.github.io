# MUME VII: Summary of Changes

MUME VII was launched in April 1999.

## Key Features
* **Chosen Statistics**: Players gain more control over their character's initial attributes.
* **Easy Char Generation**: Simplified process for creating new characters.
* **Dynamic Classes**: Characters are no longer locked into a single class but can develop skills across different areas.
* **Continuous Regeneration**: Health and mana regenerate continuously rather than in ticks.
* **Subraces**: Introduced variations within each major race.
* **Character Sets**: Support for ISO-8859-1 (Latin-1) encoding in addition to standard ASCII.
